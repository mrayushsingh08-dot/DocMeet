# 🩺 DocMeet

### Online Doctor Consultation & Healthcare Management System

DocMeet is a full-stack healthcare platform that connects patients and doctors through online appointments, video consultations, authentication, and credit-based consultation management.

## ✨ Features

- 👤 Patient & Doctor authentication
- 👨‍⚕️ Doctor profile & verification
- 🔎 Browse doctors by specialty
- 📅 Appointment booking & availability
- 🎥 Online video consultation
- 💳 Credit-based consultation system
- 🛡️ Admin dashboard
- 📊 Doctor appointment & earnings management
- 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend**

**Backend**
